# MGTS Fiber Sensing

Хакатонный проект для анализа данных распределённых температурных и
виброакустических волоконных сенсоров.

## Текущий статус

Создан минимальный каркас проекта. Предложение для JOTB-5 — постановка
регрессии, target и временная схема проверки — описано в
[`docs/ml_task_jotb_5.md`](docs/ml_task_jotb_5.md) и вынесено на командное ревью.
Трактовка служебных значений данных пока не утверждена.

## Данные

Исходные CSV хранятся локально в `MGTS_data/`, считаются неизменяемыми и не
добавляются в Git. Правила работы с данными описаны в [`data/README.md`](data/README.md).

## Установка

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -e '.[dev]'
```

## Проверка

```bash
pytest
```

Правила работы с ветками и pull request описаны в
[`CONTRIBUTING.md`](CONTRIBUTING.md).

Рабочие команды аудита, построения признаков и baseline будут добавляться
поэтапно после утверждения соответствующих решений.
