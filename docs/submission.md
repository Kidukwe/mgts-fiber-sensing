# Комплект для сдачи

Действующая постановка: task_revision.md. Ни 40 точек, ни другой размер
участка не является обязательным требованием.

Основная точка входа — `scripts/run_solution.py`.
Демонстрация — `artifacts/final/report.html`, открыть локально в браузере.
Полный комплект — `artifacts/submission.zip` после `scripts/package_solution.py`.
Для повторного обучения нужны исходные CSV, которые не входят в архив.
Для просмотра отчёта и проверки сохранённых моделей исходные CSV не нужны.

| Ожидаемый результат | Реализация | Проверка |
| --- | --- | --- |
| Python-проект и пайплайн | `solution.py`, CLI, pyproject | pytest и реальный прогон |
| Анализ предоставленных данных | Все шесть CSV, профильные карты, SHA | 6749 профилей, manifest |
| Цифровая обработка | Медианный фильтр, градиент, RMS остатка, пространственная FFT | Численные тесты, реальные признаки |

Нейросеть в доступном тексте кейса не названа обязательной. Используется обученная
регрессионная ML-модель, как допускается в ожидаемом результате. Раздельные метки
DAS и описание виброакустического канала не получены; акустическая классификация
не заявляется. Критерии скрытой проверки организаторов неизвестны.

трекера не изменялись. Публикация, отправка организаторам и эксплуатационный
деплой не выполнялись. Результат готов для проверки и демонстрации командой.
